طريقة العمل

تجهيز البيانات

تقسيم طبقي (Stratified) إلى تدريب وتحقق واختبار دون تسرّب، وتطبيع القيم، وإزاحة عشوائية مع ضوضاء خفيفة كـ Data Augmentation.

بناء النموذج

شبكة CNN من ثلاث طبقات التفافية مع Dropout. في الصور الطبية الكبيرة أستبدلها بـ ResNet أو EfficientNet مع Transfer Learning.

التدريب

AdamW مع جدولة Cosine لمعدل التعلّم وEarly Stopping على دقة التحقق، وحفظ أفضل أوزان فقط.

التقييم والتفسير

مقاييس كاملة وConfusion Matrix وSensitivity وSpecificity لكل فئة، مع Grad-CAM لإظهار مناطق الصورة المؤثرة في القرار.

مقطع من الكود

class CNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.c1 = nn.Conv2d(1, 32, 3, padding=1)
        self.c2 = nn.Conv2d(32, 64, 3, padding=1)
        self.c3 = nn.Conv2d(64, 64, 3, padding=1)
        self.drop = nn.Dropout(0.3)
        self.fc = nn.Linear(64, n_classes)

    def forward(self, x):
        f = self.features(x)          # feature maps (used by Grad-CAM)
        return self.fc(self.drop(f.mean((2, 3))))
